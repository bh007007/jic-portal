# Change Log (승인된 변경 기록)

원본은 이 파일이다(공동 작업 방식 11/10 안, `docs/collab.md`). 엑셀 `JIC_Change_Log_*.xlsx`은 이 파일에서 만든 보기용 자료다.

- **기록하는 사람**: 기획(번호·날짜·이전과 이후·사유·Leo가 할 일·상태). Claude·Leo는 '저장소 반영' 칸만 채운다.
- **번호**: CL-001부터 순서대로, 지우지 않는다. 결정을 되돌리면 새 번호로 기록한다.
- **상태**: 결정됨 → 반영 중 → 반영 완료. 철회되면 '철회'.
- **승인되지 않은 것은 코드에 넣지 않는다.** 확정 전 내용은 이 파일이 아니라 차이 목록(P-·L-·N-)과 '검토 중인 방향'에서 관리한다.
- 마지막 반영: 2026-11-10, `JIC_Change_Log_1110.xlsx`(기준 파일: 추천 조건표 V2.1 1109 승인본).
