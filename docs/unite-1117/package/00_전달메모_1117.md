## 2. 작업 원칙

1. 지금 Claude Code의 디자인 시스템과 구현된 기능을 최대한 유지합니다. 디자인은 11/11 이후 V74 기준으로 이미 적용된 현재 디자인을 그대로 씁니다.
2. 패키지의 `05_핵심페이지_화면시안.html`은 디자인 교체용이 아닙니다. 메뉴 구성과 사용자 흐름 참고용이며, 그 모양은 따르지 않습니다.
3. V74 시제품의 콘텐츠 원문을 활용하되, 이미 등록한 사진은 중복으로 옮기지 않습니다. 화면 위치만 연결합니다.
4. 임시 글 콘텐츠는 내부 미리보기에서 모두 확인할 수 있게 합니다.
5. 등록·승인·인보이스 기능은 이번 작업에서 제외합니다. 기존 경로와 링크는 그대로 둡니다.
