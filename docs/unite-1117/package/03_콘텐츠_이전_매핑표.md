## 원문 이관 알고리즘 (Claude Code 수행)

1. `02_페이지별_콘텐츠_원문.md` 및 `V74_콘텐츠_데이터.json`에서 원문을 **주제/섹션/언어/원본키**로 분해한다. 원문의 태그, 표, 리스트, 이미지 참조를 유지.
2. 현재 DB `partner_content_items`, `courses`, `campuses`와 비교해 **같음 / 초안 존재 / 비어 있음 / 충돌** 네 가지로 분류한다.
3. 기존 게시·승인 콘텐츠는 덮어쓰지 않는다. 빈 필드에는 초안으로 등록하고, 충돌 건은 별도 검토 목록으로 남긴다.
4. 각 원문에 `source=V74`, `source_key`, `source_section`, `migration_batch`, `review_status`, `updated_at`에 준하는 추적 메타데이터를 부여한다(기존 컬럼 활용 가능 시 우선).
5. 사진은 `partner-media`의 기존 자산과 **주제키/해시/경로**로 매칭한다. 없는 자산만 '누락' 보고; 재업로드 금지.
6. 국가별 노출, 언어, 공개 상태, 순서, 업데이트일 등 기존 콘텐츠 공통 속성을 보존한다.
7. 상담용 headline/benefit/evidence 설정은 같은 `content_id/course_id`를 **참조**하는 데이터로 둔다. 원문 전체 재입력 금지.
8. 프리뷰에서 원문/요약/연결 근거/자산 상태를 함께 확인한다. 검수 후에만 Published 처리.
9. 이관 실행은 `dry-run → diff 파일 → 백업 → staging import → 내부 프리뷰 QA → 승인 → 프로덕션 게시` 순.
10. 실패 시 배치 단위 롤백 가능하도록 기록한다.

## 정식 오픈 전 확인표

- [ ] 모든 V74 글 섹션에 원문 보관 위치가 있다(누락 0)
- [ ] '비어 있음' 페이지는 실제 원문이 없는 경우에만 허용
- [ ] 관리자 프리뷰에 임시 텍스트가 표시된다
- [ ] 외부 계정은 승인 전 Draft를 볼 수 없다
- [ ] 상담용 추천 문장/증거에 소스 ID를 추적할 수 있다
- [ ] 숫자·가격·정원·시간표·운영규정은 승인본에서 렌더링된다
- [ ] 기존 media를 재사용했고 사진 중복 증가가 없다
- [ ] 코스 코드 매핑에 빠진 코스가 없다
- [ ] 국가별 콘텐츠 노출 정책 위반이 없다
- [ ] 영어/한국어 등 번역 미완성 상태가 국가별 외부 공개로 이어지지 않는다

## 별도 확인 사항

V74 아티팩트 자체의 DB media 18건 및 코드에 직접 연결된 외부 blob 21개는 추출 묶음에 포함되지 않았다는 원본 명세가 있다. 하지만 사용자는 **사진 이전 완료**라고 확인했다. 따라서 **기존 Claude Code Storage에 해당 자산이 실제 존재하는지만 대조**하면 되며, 재수집을 선행 과제로 만들지 않는다.
