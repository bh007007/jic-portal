# 페이지별 화면 설계 및 기존 화면 변경 지시 (v1.0)

**표시법**: [KEEP] 기존 기능 유지, [MOVE] 위치/진입 이동, [REUSE] 공통 콘텐츠 재사용, [CHANGE] UI 수정, [NEW] 신규 연결. 실제 페이지 코드·운영 화면을 열어 검수하기 전에는 '구현 완료'라고 단정하지 않는다.

## 01. 전역 내비게이션 / 레이아웃

- [CHANGE] 사이드바를 `Dashboard / Availability / Quick Quote / Consultation / Schools & Courses / JIC Play / Materials / Updates / Contact & Visits`로 그룹화.
- [KEEP] 검색·라이트/다크·계정/국가별 접근·컴포넌트 색 토큰.
- [REUSE] 기존 페이지 URL. 허브만 추가하고 기존 상세 콘텐츠 삭제하지 않는다.
- [CHANGE] 공통 '선택한 캠퍼스' 칩은 상단 또는 검색 헤더에 표시; 모든 페이지에 무조건 캠퍼스 필터를 적용하지 않음.
- **클릭 정의**: 사이드바→허브; 허브 탭→기존 페이지; 브라우저 뒤로가기/새로고침 URL 유지; 권한 밖 액션→명확한 안내.

## 공통 인터랙션/접근성

- 모든 액션에는 실제 결과가 있어야 함(이동/열기/저장/다운로드). 미구현은 비활성+설명.
