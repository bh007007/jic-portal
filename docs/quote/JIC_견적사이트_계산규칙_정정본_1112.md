## 2. 기간 계산 — 4주 가격에서 n주 가격

### 4주 이상 (정상)
```
가격 = (4주 단가 / 4) × n주
```
즉 **주당 단가 × 주수**. 코드:
```javascript
function calcPrice(base, w) {
  // base = 4주 단가, w = 주수
  return (base / 4) * w;
}
```

### 1~3주 (단기 요율)
총 연수 기간(`curW`)이 4주 미만일 때 적용:
- **1주:** 4주 단가 × **40%**
- **2주:** 4주 단가 × **65%**
- **3주:** 4주 단가 × **85%**

```javascript
if (curW < 4) {
  if (w == 1) return base * 0.4;
  if (w == 2) return base * 0.65;
  if (w == 3) return base * 0.85;
}
```

> **주의:** 이 요율은 `curW` (전체 연수 주수)가 4 미만일 때만 적용됩니다. 혼합 캠퍼스에서 코스를 나눠 등록하더라도 전체 주수가 4주 이상이면 정상 비례 계산입니다.

### 반올림
`Math.round()` 사용 — 소수점 첫째 자리에서 반올림.

`[정정]` 학비·기숙사비의 .5는 반올림합니다. 소수점 버림은 **유학원 커미션**에만 적용합니다(견적에는 커미션 없음, CL-058).

## 3. 총액 계산 순서

### 학비 (KRW/USD/JPY)

1. **등록금** 가산 (KRW: ₩100,000 / USD: $100 / JPY: ¥14,500)
2. **코스 가격** 가산 (calcPrice로 계산, 복수 코스 합산)
3. **기숙사 가격** 가산 (calcPrice로 계산, 복수 기숙사 합산)
4. **성수기 추가요금** 가산 (해당 주수 × 주당 요금)
5. **비수기 할인** 차감
6. **홀리데이 할인** 차감
7. **장기등록 할인** 차감
8. **수동 할인** 차감 — `[정정]` 포털에는 자유 입력 수동 할인 없음(CL-076)
9. **총액** = 1 + 2 + 3 + 4 - 5 - 6 - 7 - 8 (최소 0)

`[정정]` /usd-new는 5~7 대신 Global Scholar 할인(4-6)을 차감합니다.

코드:
```javascript
document.getElementById('t-krw').innerText = '₩' + 
  Math.max(0, krw - long - dPromo - holidayPromo - holidayPromo27 - mDisc).toLocaleString();
```

### 현지 비용 (PHP)
별도 합산. PHP 항목들의 단순 합계.

`[정정]` 현지비용은 **페소로만** 표시하고 원화·달러·엔 환산은 하지 않습니다(CL-059). 공항 픽업을 신청하면 현지비용에 1회 포함합니다(CL-064).

## 4. 프로모션 상세 규칙

### 4-1. 4주 미만 차단
- **1~3주 등록 시 모든 할인 프로모션 적용 불가** (비수기, 홀리데이, 장기, Global Scholar 모두)
- **성수기 Surcharge는 주수 무관 — 날짜만 맞으면 무조건 적용**
- `[정정]` 4주 이상이면 할인은 2주 단위로 적용합니다. 비수기 금액은 4주 기준 정액이라 2주는 절반입니다(CL-061).

### 4-2. 비수기 기숙사 할인 (Lean Season)

**기간 (YYYYMMDD 숫자 비교):**
- 2026 R1: 2026-02-22 ~ 2026-06-27
- 2026 R2: 2026-08-23 ~ 2027-01-09
- 2027 R1: 2027-02-21 ~ 2027-06-26
- 2027 R2: 2027-08-22 ~ 2028-01-08

**계산:** 각 기숙사 행의 주수 중 비수기에 해당하는 주를 세고, 2주 단위로 할인(아래 금액은 **4주 기준**, 2주 = 0.5회):
```javascript
const units = Math.floor(offWeeks / 2) * 0.5;  // 2주 = 0.5회
```

**금액 (KRW / USD):**

| 기숙사 분류 | 2026 | 2027 |
|---|---|---|
| 4인실 (Room for 4) | ₩150,000 / $150 | ₩100,000 / $100 |
| 1·2인실, Semi, Couple (2026은 Room for 1 전체) | ₩50,000 / $50 | ₩50,000 / $50 (Semi, R1NB, R2, Couple만) |
| Room for 1 Balcony | `[정정]` **적용** (v88도 적용) | 적용 없음 |

`[정정]` 2026년은 1인실도 적용, **2027년은 1인실 모두 제외**(Semi·Room for 2·Couple만). 근거: 담당자 답변, 2027 프로모션 포스터 "세미1인실, 커플룸, 2인실 적용 (1인실 적용 불가)". v88의 2027 조건(`is2_2027`)에 들어 있는 Room for 1 No Balcony는 **오류 — 따르지 않음**.

**2027 eligible 조건:**
```javascript
const is2_2027 = dType.indexOf("Semi") !== -1 || 
  dType.indexOf("Room for 1 No Balcony") !== -1 || 
  dType.indexOf("Room for 2") !== -1 || 
  dType.indexOf("Couple") !== -1;
```
→ Room for 1 Balcony는 2027 비수기 할인 **미적용**

**적용 화면:** `[정정]` /kr, /usd. 일본(/jp)은 비수기 할인이 없습니다(v88도 /jp는 주수만 세고 할인 0). usd-new는 Global Scholar로 대체.

### 4-3. 성수기 추가 요금 (Peak Surcharge)

**기간:**
- 2026: 2026-06-28 ~ 2026-08-22
- 2027: 2027-06-27 ~ 2027-08-21

**계산:** 시작일로부터 매주 일요일이 성수기 기간에 해당하는지 체크
```javascript
for(let i=0; i<curW; i++) {
  const checkDay = new Date(sy, sm-1, sd + i*7);
  if (checkDay >= pStart1 && checkDay <= pEnd1) peakWeeks26++;
  else if (checkDay >= pStart2 && checkDay <= pEnd2) peakWeeks27++;
}
const peakFee = peakWeeks26 * RATE_26 + peakWeeks27 * RATE_27;
```

**요금 (연도별 차등):**

| 통화 | 2026 | 2027 |
|---|---|---|
| KRW | ₩50,000/주 | ₩80,000/주 |
| USD | $40/주 | $60/주 |
| JPY | ¥5,000/주 | ¥8,000/주 |

**중요:** 4주 미만이어도 적용됨. 프로모션이 아닌 추가 요금.

`[정정]` /usd-new도 2027년은 **$60/주**입니다. v88 3512줄은 연도 구분 없이 `peakWeeks * 40`으로 계산하는 오류입니다(CL-061).

### 4-4. 홀리데이 프로모션 (Holiday)

**조건:**
1. 시작일이 홀리데이 지정 날짜 중 하나
2. 총 주수 4주 이상
3. **eligible 기숙사(2인실/4인실/Couple) 합산 4주 이상** (Room for 1, Semi-Single 제외)

**2026 홀리데이 시작일:** 2026-11-29, 2026-12-13, 2026-12-27, 2027-01-10
**2027 홀리데이 시작일:** 2027-11-28, 2027-12-12, 2027-12-26, 2028-01-09

```javascript
const holidayExcludedRow = dType.indexOf("Room for 1") !== -1 || dType.indexOf("Semi") !== -1;
if (!holidayExcludedRow) holidayEligibleWeeks += w;
// ...
if (isHolidayStart26 && curW >= 4 && holidayEligibleWeeks >= 4) { ... }
```

**금액 (1회성 정액):**

| 통화 | 2026 | 2027 |
|---|---|---|
| KRW | ₩200,000 | ₩150,000 |
| USD | $200 | $150 |
| JPY | ¥30,000 | 삭제 (적용 없음) |

`[정정]` 2027 포스터는 홀리데이 대상을 "2인실, 4인실 (1인실, 세미1인실 적용 불가)"로 적어 커플룸이 없습니다. v88은 커플룸 포함 — **커플룸 포함 여부 확인 필요**. 포스터 기준일은 '출국일'이며 견적에서는 시작일로 계산합니다.

**적용 화면:** /kr, /usd, /jp (usd-new 없음)

### 4-5. 장기 등록 프로모션 (Long-term)

**조건:** 12주 이상
**공식:** 기본 금액 + floor((주수 - 12) / 2) × 증가분

| 통화 | 기본(12주) | 2주당 증가 | 예: 24주 |
|---|---|---|---|
| KRW | ₩300,000 | ₩50,000 | ₩600,000 |
| USD | $300 | $50 | $600 |
| JPY | ¥10,000 | ¥5,000 | ¥40,000 |

```javascript
const long = curW < 12 ? 0 : 300000 + Math.floor((curW - 12) / 2) * 50000;
```

24주 이후에도 계속 증가합니다.

**적용 화면:** /kr, /usd, /jp (usd-new 없음)

### 4-6. Global Scholar 프로모션 (USD-New 전용)

**/usd-new에만 적용.** 비수기/홀리데이/장기 대신 이 프로모션 적용.

**2026 (2주 단위):**
- Lean: $200 / 2주 (기간: 02/22~06/27, 08/23~12/26)
- Peak: $100 / 2주 (기간: 06/28~08/22)

**2027 (4주 단위):**
- Lean: $400 / 4주 (기간: 02/21~06/26, 08/22~01/08)
- Peak: $200 / 4주 (기간: 06/27~08/21)

**Peak Surcharge:** $40/주 (2026), $60/주 (2027) — 별도 추가 (`[정정]` v88은 2027도 $40 — 따르지 않음)

**4주 미만 적용 불가**

### 4-7. 할인 중복 적용

**동시 적용 가능한 조합:**
- 비수기 할인 + 장기 할인 + 홀리데이 = 모두 동시 적용 가능
- 비수기 할인 + 성수기 Surcharge = 동시 적용 가능 (비수기/성수기는 기간이 다름)
- 수동 할인은 항상 추가 가능 — `[정정]` 포털에는 자유 입력 수동 할인 없음. 대만 Fair promotion은 담당자 확인 후 적용(2차, CL-076). 중복 규칙은 담당자 미팅에서 확인

**적용 순서:** 모두 독립적으로 계산 후 총액에서 차감

## 5. 통화

### 가격 구조
- **KRW, USD, JPY 가격은 각각 독립적으로 정해진 값** (환율 계산 아님)
- 각 통화별 코스/기숙사 단가가 코드에 하드코딩
- 환율은 **PHP 현지 비용의 참고 환산**에만 사용

### PHP 환율 (참고 환산용)

| 페이지 | 기본값 | 용도 |
|---|---|---|
| /kr | ₱1 = ₩23 | PHP 합계의 원화 참고 환산 |
| /usd | ₱1 = $0.017 | PHP 합계의 달러 참고 환산 |
| /usd-new | ₱1 = $0.017 | 동일 |
| /jp | ₱1 = ¥2.6 | PHP 합계의 엔화 참고 환산 |

- 사용자가 화면에서 직접 수정 가능 (input 필드)
- **코드 변경 시 개발자가 직접 수정** (기본값 하드코딩)
- `[정정]` 포털에서는 환산하지 않습니다. 현지비용은 페소로만 표시(CL-059)

### /usd vs /usd-new 차이
- **/usd** (TW·CN·SA): 비수기/홀리데이/장기등록 프로모션 적용
- **/usd-new** (VN·TH·MY·FR 등): Global Scholar 프로모션만 적용 (비수기/홀리데이/장기 없음)

`[정정]` 포털에서는 유학원 계정 국가로 자동 선택: 한국 /kr, 일본 /jp, 대만·중국·사우디 /usd, **그 밖의 모든 국가 /usd-new**(CL-063).

## 6. 견적서 양식

### 화면 구성
- **헤더:** JIC 로고 + 캠퍼스명 + 견적일 + 통화
- **캠퍼스 탭:** 챌린저 / 프리미엄 / 혼합 (CC+PC)
- **입력 영역:** 기본정보, 기간선택, 코스/기숙사 선택, 픽업, 수동할인 (`[정정]` 포털은 수동할인 없음)
- **결과 영역:** 학비 합계 + PHP 현지비용 합계

### 인쇄/PDF 양식
- `html2pdf.js` 라이브러리 사용
- 인쇄 시 입력 영역 숨김, 결과 영역만 표시
- 인쇄 헤더에 로고 + 캠퍼스명 + 견적일 표시
- 요약 정보 박스 표시 (유학원, 학생, 성별, 생년월일, 시작일, 종료일, 기간, 픽업, 코스, 기숙사)

### 고정 문구 (언어별)

**KRW:**
> ※ 상기 현지 비용은 필리핀 이민국의 정책 변경, 인상 및 환율 변동 등에 따라 실제 납부 금액이 달라질 수 있습니다.

**USD/USD-New:**
> ※ Local fees are subject to change due to Philippine immigration policy changes, rate adjustments, and exchange rate fluctuations.

**JPY:**
> ※ 現地費用はフィリピン移民局の政策変更・料金改定・為替変動により変更される場合があります。

### 유효기간
`[정정]` 유효기간 없음. 정식 견적서와 재발행 기록은 업체 포털 학생등록에서 관리합니다(포털 견적은 가견적, CL-067).

### 계좌 정보
`[정정]` 견적서에는 넣지 않음. 계좌 정보는 유학원 인보이스에만 들어갑니다(CL-067).

## 8. 운영 방식

| 항목 | 현재 상태 |
|---|---|
| 가격 변경 주체 | JIC 내부 담당자 (코드 직접 수정) |
