## 4. 포털에서 막을 입력 (혼합 등록, CL-062)

1. 캠퍼스별 기간마다 코스와 숙소가 같은 캠퍼스
2. 숙소 주수 합 = 코스 주수 합 = 총 연수 기간
3. 캠퍼스별로 코스·숙소 모두 최소 4주
4. 캠퍼스 기간은 앞뒤로 이어 붙임 (IELTS Guarantee는 항상 마지막 8주)

**시험용 예 (막혀야 정상)**: /kr 혼합, 2026-07-05, 12주, [CC] ESL Flex 8주 + [PC] Working Holiday 8 4주, 숙소 [CC] Room for 1 (studio) 12주 + [PC] Couple Room Balcony 1주. v88은 ₩7,922,500으로 계산하지만 1·2·3을 모두 어깁니다.

## 5. 확정된 계산 규칙 요약

- **반올림**: 학비·기숙사비 .5는 반올림. 소수점 버림은 2차 커미션에만 (CL-058)
- **4주 미만**: 할인 프로모션 없음, 성수기 추가요금만 적용
- **4주 이상**: 할인은 2주 단위. 비수기 금액은 4주 기준 (2주 = 절반)
- **장기등록**: 12주 이상이면 무조건 (/kr·/usd·/jp)
- **일본**: 장기·홀리데이만, 비수기 없음
- **성수기 추가요금**: 2026 ₩50,000 / $40 / ¥5,000, 2027 ₩80,000 / $60 / ¥8,000 (주당, /usd-new 포함)
- **2027 비수기 1·2인실**: Semi·Room for 2·Couple만, 1인실은 모두 제외 (포스터)
- **IELTS Guarantee 공식 시험 50% 지원(2027)**: 학비 할인이 아니므로 견적 계산에 넣지 않음 (공지 콘텐츠, T-34)
- **Global Scholar** (/usd-new만, 장기·비수기·홀리데이 대신): 26년 2주당(Lean $200, Peak $100), 27년 4주당(Lean $400, Peak $200)
- **가격 체계 자동 선택**: 한국 /kr, 일본 /jp, 대만·중국·사우디 /usd, 그 밖의 모든 국가 /usd-new (CL-063)
- **공항 픽업**: v88 선택지 4개 그대로, 현지비용에 1회 포함, 단체(BESA)는 ₱3,000 (CL-064)
- **현지비용**: 페소로만, 환산 없음, 하단 고정 문구 (CL-059)
- **견적서**: 유효기간 없음, 계좌 없음, 커미션 없음 (CL-067)
- **연수 기간**: 1주부터 선택 가능
