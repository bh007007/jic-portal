# 견적 기능 포털 통합 답변 (R-013)

기획 요청 R-013(11/11, 작업 전 결정): 견적 사이트(quote.baguiojic) 기능을 상담 ⑤ 비용 단계와 관리자 포털로 옮기고, 가격은 관리자 포털 가격표 한 곳에서 입력·수정한다. 아래는 Leo 답변이다. 견적 자료 9종을 받기 전이라 지금 견적 화면 코드(공개 화면 4개)를 보고 판단했다(`docs/price-quote-link.md`).

## ① 가능 여부와 대략 일정

**가능하다.** 견적 사이트의 계산은 화면 스크립트 안에 있고 규칙이 단순해서 포털로 옮길 수 있다.

| 단계 | 내용 | 기간(자료를 받은 뒤, 작업일) |
| --- | --- | --- |
| 1 | 가격표 정리: 견적 사이트 값으로 채움(CL-057), 이름 대응표, 적용 시작·종료일 | 1일 |
| 2 | 계산 규칙을 데이터로: 기간 비율, 교재비, 현지 비용(SSP·I-Card·비자 연장·픽업 등), 할인 규칙 | 1~2일 |
| 3 | 상담 ⑤ 견적 화면과 견적서(인쇄·PDF, 저장 안 함) | 1~2일 |
| 4 | 관리자 '가격표' 수정 화면(T-21): 적용 기간, 변경 이력, 승인 | 1~2일 |
| 5 | 검증: 예시 견적 10건이 견적 사이트와 같은 금액인지 자동 시험 | 1일 |

합계 5~8작업일. 가격 승인자와 상품 이름 대응이 정해지면 1단계부터 시작한다. 견적 사이트는 5단계가 끝날 때까지 그대로 운영한다(T-22).

## ② 걸리는 점

1. **학생 입력 항목(P3)**: 견적 화면에 학생 이름 칸이 있다. 포털 견적은 학생 이름을 **저장하지 않고**, 화면과 인쇄·PDF에만 쓴다. 상담 끝내기(CL-049)에서 지운다. 견적 기록이 필요하면 학생 정보 없이(코스·기간·금액·지점) 남긴다. 어느 쪽인지 기획 확인이 필요하다.
2. **통화**: 지금 견적 사이트는 환율로 바꾸지 않는다. 원·엔·달러 화면마다 **값을 따로 적어 둔다**(예: 같은 코스의 원 값과 달러 값이 따로 있음). 업체 가격표도 통화별 값(`cc_won`·`cc_usd`·`cc_yen`)이다. 그래서 포털도 **통화별 가격을 따로 입력**하는 방식을 제안한다. 현지 비용은 페소(PHP)로 따로 보인다. 환율로 자동 계산하려면 새 결정이 필요하다.
3. **할인 규칙**: 견적 화면에 비수기 기숙사 할인(2026·2027 기간, 4인실·1·2인실별 금액, 2주마다 할인)이 코드로 들어 있다. 프로모션 화면(`/usd-new`)도 따로 있다. 포털에서는 '할인 규칙' 표(캠퍼스, 방 종류, 적용 기간, 단위, 금액, 국가)로 옮긴다. 할인끼리 겹칠 때 규칙을 받아야 한다.
4. **현지 비용 규칙**: SSP는 6개월마다, I-Card는 1년마다 다시 내고, 비자 연장비는 주 수별, 전기·세탁·시설비는 4주 단위다. 견적 코드의 규칙을 그대로 데이터로 옮기고 예시로 검증한다.
5. **상품 이름**: 조건표 V2.1 코스 이름, 견적 사이트 이름, 업체 가격표 이름이 다르다(22개, `docs/price-quote-link.md` 2장). 대응표 한 장이 기준이 된다(CL-056).
6. **국가별 화면**: 지금 KR·JP·USD·USD-New 네 화면이다. 포털은 지점 국가로 통화와 프로모션을 고른다(CL-036과 같은 방식).

## ③ 받고 싶은 자료 형식

- **견적 사이트 소스**: 네 화면의 HTML 파일 그대로(지금 공개 화면과 같아도 됨).
- **엑셀 한 파일**에 시트별로:
  1. 상품 이름 대응표: 조건표 코스·단계 ↔ 견적 사이트 이름 ↔ 업체 가격표 이름
  2. 가격: 캠퍼스, 상품, 통화(KRW·JPY·USD), 4주 가격, 적용 시작일·종료일
  3. 현지 비용: 항목, 페소 금액, 계산 단위(1회·4주·6개월 등), 조건
  4. 할인 규칙: 이름, 캠퍼스, 방 종류, 적용 기간, 단위, 금액, 국가, 겹칠 때 규칙
  5. 기간 비율: 1~3주 비율(지금 40·65·85%), 4주 넘으면 주 단위 계산
  6. 견적서 양식: 화면 사진 또는 PDF 한 장
  7. **검증 예시 10건**: 입력(캠퍼스·코스·단계·기숙사·기간·시작일·픽업·국가)과 견적 사이트가 낸 금액(항목별·합계)
- 운영 방식: 가격을 누가 바꾸고 누가 승인하는지, 바뀌면 언제부터 적용하는지
