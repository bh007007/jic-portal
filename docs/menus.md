# 앱별 메뉴·화면·권한 (현재 저장소 기준)

공동 작업 방식(11/10 안)에서 메뉴·화면·권한의 원본 자리다. 지금 내용은 **2026-11-10 코드에 실제로 있는 메뉴**를 옮긴 것이다. 기획의 메뉴 검토표·사이트맵·권한표와 다른 곳은 차이 목록으로 맞추고, 결정되면 이 파일과 코드를 같이 고친다(`docs/change-log.md`).

- 메뉴를 더하거나 빼기 전에 "이 데이터는 어디서 입력하는가"(원칙 C2)를 먼저 확인한다. 입력처는 `docs/principles.md`, 권한(역할)은 `docs/roles.md`.
- CL-025: 직원 화면은 하나의 통합 관리 앱으로 간다. 지금은 관리자 앱(`/admin/`)이 기반이고, 인트라넷(`/intranet/`)·강사 포털(`/teacher/`)은 같은 로그인으로 오가는 별도 앱이다. 메뉴 그룹별 권한(보기·입력·승인) 설계는 다음 일이다.
- CL-026: PC 기준으로 먼저 만든다. 태블릿·모바일 대응은 메뉴가 확정된 뒤에 한다(화면 폭은 고정하지 않음).
- '준비 중'은 메뉴만 있고 화면이 없다는 뜻이다(원칙 C8).
