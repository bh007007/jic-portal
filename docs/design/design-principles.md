# JIC 포털 디자인 원칙 v1

2026-11-11 · 기획 · 근거 CL-041 · 저장소 위치 `docs/design/design-principles.md`

디자인 원본은 파트너 포털 시제품 V74(2026-10-23)입니다. 11/07 디자인(네이비, 상단 메뉴)은 이 문서로 대체합니다. 이 문서를 바꿀 때는 새 CL 번호로 기록합니다.

## 1. 원칙

| 번호 | 원칙 | 뜻 |
| --- | --- | --- |
| D1 | 디자인 기준은 하나 | 파트너 포털, 통합 관리 앱(관리자·인트라넷·강사 포털), 학생 앱이 같은 색·글꼴·부품을 씁니다. 사이트마다 다른 것은 강조색과 화면 밀도뿐입니다. |
| D2 | 캠퍼스 색은 정보 | 캠퍼스를 구분할 때만 쓰고 장식으로 쓰지 않습니다. 색만으로 구분하지 않고 항상 캠퍼스 이름을 함께 씁니다. |
| D3 | 파트너 포털은 콘텐츠가 주인공 | 사진과 영상은 상담 도구라서 크게 보여 줍니다. 확인된 내용만 싣고, 비어 있으면 '준비 중' 배지를 답니다(C8). |
| D4 | 관리 화면은 일 처리가 먼저 | 표·검색·필터를 같은 모양으로 반복합니다. 기본 강조색은 중립 그래파이트입니다. |
| D5 | 모든 기기에서 쓸 수 있게, PC부터 | 모든 사이트(강사 포털·학생 앱 포함)를 PC 기준으로 먼저 만들고, 태블릿·모바일은 메뉴 확정 후 추가합니다(CL-026, CL-042). 처음부터 폭을 고정하지 않고, 나중에 화면 크기별 배치를 더할 수 있게 만듭니다. 이미 휴대폰 기준으로 만든 화면은 그 배치를 지우지 않습니다. 다크 모드를 지원합니다. |
| D6 | 사진과 문구는 캠퍼스 브랜드 톤 | Premium: Speak Yours · Live the English. 따뜻하고 사람 중심(웃는 얼굴, 대화, 친구). Challenger: #1 IELTS · Take the Challenge. 목표와 집중(시험, 노트, 발표). |
| D7 | 누구나 읽을 수 있게 | 글자 13px 이상, 버튼 높이 40px 이상(작은 버튼 32px), 키보드 포커스 표시, 글자와 배경의 대비를 충분히 둡니다. |
| D8 | 6개 언어 전제 | 문구는 코드에서 분리합니다(P7). 번역되면 글이 길어지므로 버튼·메뉴에 여유를 두고, 한 줄 고정 폭을 쓰지 않습니다. |
| D9 | 디자인 변경은 모양만 | 메뉴, 화면 순서, 버튼 이름과 연결, 기능은 CL로 정한 것을 따릅니다. 시제품은 모양과 콘텐츠의 기준이지 기능의 기준이 아닙니다. |

## 2. 기준값

값은 시제품 V74 코드 그대로입니다. CSS 변수 이름도 그대로 쓰는 것을 권합니다.

### 2.1 캠퍼스 색 (밝은 화면)

| 이름 | 변수 | 기본 | 연한 배경 | 진한 글자 | 쓰는 곳 |
| --- | --- | --- | --- | --- | --- |
| 전체(통합) | `--all` | `#4C5260` | `#E4E6EA` | `#272A31` | 캠퍼스와 상관없는 화면, 관리 화면 기본 |
| Premium | `--pre` | `#5B8A6E` | `#E2ECE1` | `#214632` | Premium 화면·배지 (보조 허니 `#E2B867`) |
| Challenger | `--cha` | `#C23B4A` | `#F7E0E2` | `#7A1E2A` | Challenger 화면·배지 (보조 차콜 `#24272C`) |
| New Campus | `--new` | `#6E8FCB` | `#D9E3F5` | `#28497F` | New Campus(준비 중) |
| 주니어 캠프(MCO) | `--mco` | `#C9962E` | `#F3E6D2` | `#6E5228` | 주니어·가족 캠프 |

화면이 한 캠퍼스에 속하면 `body[data-campus="pre|cha|new|mco"]`로 강조색(`--accent`)이 그 캠퍼스 색으로 바뀝니다. Premium 화면은 배경도 아이보리(`#F8F5EE`)로 따뜻하게 바뀝니다.

### 2.2 기본 색

| 용도 | 밝은 화면 | 어두운 화면 |
| --- | --- | --- |
| 배경 `--bg` | `#F7F8FA` | `#1A1C21` |
| 카드 `--surface` / 보조 `--surface-2` | `#FFFFFF` / `#FAFBFC` | `#22252B` / `#262930` |
| 선 `--line` / 옅은 선 `--line-2` | `#E5E7EB` / `#EFF1F4` | `#33373F` / `#2C2F36` |
| 글자 `--ink` / 보조 `--ink-2` / 흐린 `--muted` | `#262A31` / `#4B5260` / `#6B7280` | `#E8EAEE` / `#C2C7D0` / `#9CA3AF` |
| 주의 배경·글자 | `#FBF4E4` / `#8A6A22` | `#3A3222` / `#E6C987` |
| 사이드바 / 사이드바 글자 | `#24272C` / `#C9CDD4` | `#16181C` / `#C9CDD4` |

어두운 화면의 캠퍼스 색: Premium `#86B9A1`, Challenger `#DD959D`, New `#97B1E2`, 전체 `#A3A9B6` (연한 배경·진한 글자 값은 시제품 코드 참조).

### 2.3 로고 색

JIC 로고 레드 `#D52B1E`는 **로고에만** 씁니다. Challenger 캠퍼스 색 `#C23B4A`와 섞어 쓰지 않습니다.

### 2.4 글꼴

- 글꼴 순서: `"IBM Plex Sans KR", "Noto Sans KR", "Noto Sans JP", "Noto Sans SC", "Noto Sans TC", "Apple SD Gothic Neo", "Malgun Gothic", system-ui, sans-serif`
- IBM Plex Sans KR은 한국어·영어만 담고 있어, 일본어·중국어·베트남어는 뒤의 Noto 글꼴이 이어받습니다.
- 본문 15px, 줄 간격 1.6, 한국어 단어 단위 줄바꿈(`word-break: keep-all`)

| 용도 | 크기 | 굵기 |
| --- | --- | --- |
| 화면 제목 h1 | 26px | 600 |
| 소제목 h2 / h3 | 17px / 15px | 600 |
| 본문 | 15px | 400 |
| 작은 글·버튼 | 13~14px | 400~500 |
| 표 본문 / 표 머리 | 14px / 12.5px | 400 / 500 |
| 숫자 카드(KPI) 값 | 26px | 600 |

### 2.5 모양

| 부품 | 기준 |
| --- | --- |
| 모서리 | 큰 카드 18px, 중간 12px, 작은 요소 8px |
| 카드 | 흰 배경, 1px 선, 안쪽 여백 22px, 그림자는 아주 옅게 |
| 버튼 | 높이 40px, 모서리 11px. 주 버튼은 강조색 연한 배경 + 진한 글자. 작은 버튼 32px |
| 배지·칩 | 둥근 알약 모양. '준비 중' 배지는 주의 색 |
| 표 | 위아래 옅은 선, 칸 여백 12px 16px, 머리는 보조 배경 |
| 알림 | 주의 배경 + 아이콘. 안내용은 강조색 연한 배경 |
| 아이콘 | 18px 선 아이콘(선 굵기 1.6) |
| 포커스 | 강조색 2px 테두리 |

### 2.6 배치 (PC)

- 왼쪽 사이드바 232px(차콜) + 본문
- 본문 위쪽 고정 막대(반투명 배경)
- 본문 최대 폭 1240px, 안쪽 여백 28px 32px
- 화면 머리: 제목, 한 줄 설명, 오른쪽에 주요 버튼

## 3. 사이트별 적용

| 사이트 | 강조색 | 밀도 | 적용 시점 |
| --- | --- | --- | --- |
| 파트너 포털 | 캠퍼스 화면은 그 캠퍼스 색, 나머지는 그래파이트 | 사진 크게, 여백 넉넉히 | **지금** (CL-041) |
| 통합 관리 앱 (관리자·인트라넷·강사 포털) | 그래파이트 | 표·필터 중심, 촘촘하게 | 목요일 메뉴 확정 뒤 한 번에. 그 전에 새로 만드는 관리 화면은 지금 모양으로 만들고 함께 바꿈 |
| 학생 앱 | 학생의 캠퍼스 색 | 큰 글씨·큰 버튼 | 메뉴 확정 뒤 |

## 4. 파트너 포털 적용 시 지킬 것 (D9)

시제품 화면을 옮길 때 아래는 시제품이 아니라 지금 포털(CL)을 따릅니다.

- 메뉴 구조와 위치: CL-037
- 로그인 후 홈 순서: CL-040 (맨 위 '학생과 함께 상담 시작'은 그대로, 모양만 새 디자인)
- 상담: 추천 조건표 V2.1 흐름. 시제품의 '과정 진단', 러닝 플랜, Active Senior·가족 연수 추천은 가져오지 않음(CL-030)
- 학비: 화면의 학비표는 가격표 원본에서 읽음(CL-038). 시제품의 학비표 이미지는 쓰지 않고, 학비표 PDF는 자료실 내려받기용
- 캠퍼스 비교 표, 문의·상담 관리는 가져오지 않음(CL-030)
- 계정과 직원 아이디: CL-032
- 국가별 노출과 순서: CL-036
