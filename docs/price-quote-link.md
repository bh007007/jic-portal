# 가격표와 견적 사이트 연결 검토 (R-009, CL-038)

CL-038: 관리자 포털 가격표(공용 DB)가 학비·가격의 원본이다. 에이전시 포털 학비표는 가격표에서 읽는다(반영 완료). 견적 사이트는 연결 전까지 그대로 둔다.
기획 요청 R-009는 가격표와 견적 사이트를 연결하는 방법의 검토다. 이 문서가 그 결과다. 결정 전에는 견적 프로그램도 포털 코드도 바꾸지 않는다.

## 1. 지금 상태

**견적 프로그램**(https://quote.baguiojic.workers.dev/, baguiojic Cloudflare 계정, `docs/quote-prefill.md`)
- 화면이 네 개다: `/kr`(원), `/jp`(엔), `/usd`(달러), `/usd-new`(달러, 프로모션만).
- 가격은 화면마다 스크립트 안에 **직접 적혀 있다.** `DATA[캠퍼스].t[코스]`·`.d[기숙사]` = 그 화면 통화의 4주 가격이다.
- 기간 계산은 `4주 가격 ÷ 4 × 주 수`다. 1~3주는 40·65·85%다. 업체 가격표의 기간별 값(`cs_*`, 4주 = 100)과 같은 규칙이다.
- 현지 비용(PHP)도 코드에 적혀 있다: SSP·I-Card·학생증·보증금·전기·세탁·시설·비자 연장·픽업·IELTS Guarantee 비용·교재비.
- 할인도 코드에 적혀 있다: 비수기 기숙사 할인 2026·2027 기간 등.

**관리자 포털 가격표**(`/prices`, `core.ts` prices)
- 업체 가격표 추출본(11/9)을 **읽기만** 한다. 관리자 포털에서 가격을 고치는 화면은 아직 없다.
- 운영 DB(`legacy_prices`)에는 가짜 샘플만 있다. 실제 가격표는 하드디스크에만 있다(보안 점검 전).

## 2. 두 가격 비교 (11/10)

`node scripts/quote-price-compare.mjs`로 비교했다. 견적 공개 화면의 가격과 하드디스크의 업체 가격표(개인정보 없음) 중 오늘 적용분을 맞대었다.

**코스·기숙사**(원·엔·달러 × 프리미엄·챌린저, 93칸)
- 이름 짝을 맞추면 **87칸이 같고 다른 칸은 0**이다.
- **가격표에 없는 것 6칸**: 챌린저 `ESL Core`·`IELTS Core`(세 통화). 견적 프로그램에만 있다.
- 이름이 다른 것 22개는 아래 짝으로 맞춘다(`scripts/quote-price-compare.mjs`의 MAP).

| 캠퍼스 | 견적 프로그램 이름 | 가격표 이름 |
| --- | --- | --- |
| 프리미엄 코스 | Active Senior 5·6 / Working Holiday 8 / TOEIC | ESL Active Senior (AS 5)·(AS 6) / WH ESL / TOEIC 8 |
| 프리미엄 기숙사 | Room for 1·2·4 Balcony / No Balcony | R1·R2·R4 (Bal) / R1·R2·R4 |
| 프리미엄 기숙사 | Semi-Single / Couple Room Balcony | Semi Single_2nd floor (F)·_1st floor (M) / Couple Room (Bal) |
| 챌린저 코스 | ESL Flex·Lite·Standard / IELTS Lite·Standard | ESL-Flex·-Lite·-Standard / IELTS-Lite·-Standard |
| 챌린저 코스 | IELTS Guarantee | IELTS-G (8W)(4주로 환산하면 같음) |
| 챌린저 기숙사 | Room for 1·2 (studio) / Room for 4 (loft)·(studio) | R1·R2 Studio / R4 Loft·R4 Studio |

**값이 다르거나 정리할 것**
- **IELTS Guarantee 12주**: 견적은 4주 가격 × 3 = 4,200,000원이다. 가격표에는 `IELTS-G (12W)` 4,050,000원이 따로 있다.
- 가격표에는 옛 이름 줄(챌린저 `IELTS Standard`·`IELTS Guarantee`, 견적보다 낮은 값)이 아직 '적용 중'으로 남아 있다.
- **현지 비용(PHP)**: 짝으로 보이는 줄을 비교했다.

  | 항목 | 견적 프로그램 | 가격표 |
  | --- | --- | --- |
  | SSP(6개월) | 7,800 | 6,800 |
  | SSP I-Card | 4,500 | 4,000(`ACR I-CARD` 3,500 줄도 있음) |
  | 픽업 마닐라 1인(다른 날) | 13,000 | 12,000 |
  | 픽업 클라크 1인(다른 날) | 8,500 | 7,000 |
  | 픽업 클라크 월요일(BESA) | 3,000 | 2,500 |

  같은 것: 마닐라 일요일 픽업 3,000, 학생증 200, 기숙사 보증금 3,000, 전기·수도 4주 3,000.
  비교하지 않은 것: 세탁·시설·비자 연장·교재비·프로모션.

**뜻**
- 코스·기숙사 가격은 두 곳이 거의 같아 연결할 수 있다.
- 현지 비용은 어느 쪽이 맞는지 먼저 정해야 한다. 견적 프로그램 쪽이 최근 값으로 보이지만 확인이 필요하다.
- CL-038 학비표에도 걸린다. 실제 가격표를 운영 DB에 올리면 에이전시 학비표 '기타 비용'에 가격표 값(예: SSP 6,800)이 보인다. 견적 금액과 어긋날 수 있다. **실제 가격표를 올리기 전에 기준값을 정리해야 한다.**

## 3. 연결 방법

| 안 | 내용 | 좋은 점 | 걸리는 점 |
| --- | --- | --- | --- |
| **가(추천)** | 견적 프로그램이 열릴 때 JIC 포털의 **견적용 가격 주소**에서 지금 적용 가격을 읽는다. 계산·화면은 견적 프로그램 그대로 | 가격을 한 곳(관리자 가격표)에서만 고친다. CL-038 '연결'과 원칙 Q1(견적은 견적 프로그램)을 둘 다 지킨다 | 관리자 포털에 가격 수정 화면이 있어야 한다. 견적 프로그램 수정이 필요하다(baguiojic 계정 담당) |
| 나 | 관리자 포털이 '견적용 가격 파일'을 내보내고, 견적 담당이 붙여 넣는다 | 견적 프로그램이 포털에 기대지 않는다. 가장 빨리 할 수 있다 | 손으로 옮기므로 다시 어긋난다. 원본이 하나라는 CL-038 취지에 약하다 |
| 다 | 견적 계산을 JIC 포털로 옮긴다 | 완전히 한 시스템이 된다 | CL-038 '견적 사이트는 그대로', 원칙 Q1과 다르다. 견적 화면의 학생 정보 칸이 P3에 걸린다. 지금은 추천하지 않는다 |

**가안의 견적용 가격 주소**
- 로그인 없이 읽는 주소가 된다. 이미 견적 화면에 공개된 값과 같은 범위만 내보낸다: 코스·기숙사 4주 가격, 현지 비용. 커미션·환율 원본·프로모션 설정은 넣지 않는다.
- DB 함수를 익명에게 열지 않는다(보안 점검 규칙). JIC 포털 서버(Pages Function)가 읽어 정리한 결과만 준다. 짧게 캐시하고, 견적 프로그램 주소에서만 부를 수 있게 한다.
- 견적 프로그램은 주소를 못 읽으면 지금 내장된 값으로 계산하고 '가격 확인 필요'를 띄운다.

## 4. 순서(가안)

1. **기준값 정리**: 위 '값이 다르거나 정리할 것'을 정한다. 현지 비용 5건, IELTS-G 12주, ESL·IELTS Core, 옛 이름 줄이다. 기획·센터장이 정한다.
2. **관리자 포털 가격 수정**: 가격표를 업체 추출본(`legacy_prices`)이 아닌 JIC 표로 옮기고 수정 화면을 만든다. 권한은 `docs/permissions.md`의 '가격표 수정(승인 권한 후보)'이다. DB 설계는 DB 관리자, 기능은 Change Log 승인 뒤에 만든다.
3. **견적 표시 이름**: 가격표 줄마다 견적 화면에 보일 이름을 둔다. 위 짝 표가 시작점이다.
4. **견적용 가격 주소**: 1~3이 끝나면 만든다. 학비표(`partner_tuition()`)와 같은 기준(오늘 적용, 사용 중)을 쓴다.
5. **견적 프로그램 수정**: 네 화면이 주소에서 가격을 읽게 바꾼다. 견적 프로그램 담당이 baguiojic 계정에서 한다. 미리 채우기 코드(`docs/quote-prefill.md`)와 같이 넣으면 한 번에 끝난다.
6. **할인·교재비·비자 연장비**: 1단계에서는 견적 프로그램에 그대로 둔다. 프로모션 관리를 어디서 할지 정한 뒤에 옮긴다.
