## 1. 결과 블록 배치 (견적-1)

왼쪽 입력, 오른쪽 결과 배치는 **그대로** 둡니다(입력을 바꾸면 결과가 바로 바뀜). 오른쪽 결과만 아래 순서와 모양으로 바꿉니다.

| 순서 | 구역 | 내용 |
|---|---|---|
| 1 | 머리 | "견적" + 인쇄·PDF 버튼, 아래 작은 글씨 `시작일 ~ 종료일 · n주 · 캠퍼스` |
| 2 | 코스 | 줄마다 코스 이름 · 금액, 아래 작은 글씨 `n주 · 시작일 ~ 종료일` |
| 3 | 숙소 | 코스와 같은 모양 |
| 4 | 코스+숙소 | 소계, 옅은 배경(`--surface-2`) |
| 5 | 등록금 | |
| 6 | 할인 · 추가요금 | 2장 이름, 3장 색, 4장 아이콘. 줄마다 이름(큰 글씨) + 계산 근거(작은 글씨) |
| 7 | 총 학비 | 굵게, 금액 22px |
| 8 | 현지비용 (페소, 현지 납부) | 지금과 같음(항목, 합계, 안내 문구 2줄) |

- 코스·숙소가 여러 줄이면 줄마다 기간과 날짜가 붙습니다(넣은 순서 = 기간 순서).
- **혼합 탭**: 코스·숙소 줄 이름 옆에 작은 캠퍼스 칩(Premium / Challenger, 5장 색)을 붙입니다.
- **넣지 않을 것**: 유학원 커미션(학생에게 보이는 화면, CL-076 ④), 현지비용 원화 환산(페소만 표시).
- **2차 재사용**: 같은 결과 블록을 학생등록 3단계와 인보이스에서 그대로 씁니다(R-014: 같은 계산 + 같은 모양). 커미션은 인보이스에서만 블록 아래에 따로 붙입니다.

## 2. 프로모션 표시 이름 (견적-2)

유학원에게 익숙한 이름을 **큰 글씨**로, 계산 근거를 **작은 글씨**로 보여 줍니다. 관리자 프로모션 표의 이름("비수기 4인실 '26" 등)은 관리용으로 그대로 두고, 화면 표시 이름을 따로 둡니다.

| 프로모션 표 (관리용) | 표시 이름 (한국어) | 표시 이름 (영어) | 작은 글씨 (계산 근거) | 종류 |
|---|---|---|---|---|
| 비수기 1·2인실 '26 / 4인실 '26 / '27 | 린시즌 기숙사 할인 | Lean Season Dorm Discount | `Lean '26 · 방 이름 · n주 → n회 × 금액` | 할인 |
| 홀리데이 '26 / '27 | 홀리데이 프로모션 | Holiday Promotion | `Holiday '26 · 시작 날짜 · 대상 방 n주` | 할인 |
| 장기등록 | 장기등록 할인 | Long-term Discount | `12주 이상` | 할인 |
| Global Scholar '26·'27 Lean·Peak | Global Scholar 프로모션 | Global Scholar Promotion | `Lean '26 · n주` (계산은 정정본 규칙) | 할인 |
| 성수기 추가요금 '26 / '27 | 피크시즌 추가요금 | Peak Season Surcharge | `Peak '26 · 방 이름 · n주 × 금액` | 추가요금 |
| Fair promotion(대만) | Taiwan Fair Promotion | Taiwan Fair Promotion | 2차 인보이스에서 담당자 적용 | 할인 |

- 비수기가 '26과 '27에 걸치면 같은 이름으로 **두 줄**, 작은 글씨의 `Lean '26` / `Lean '27`로 구분합니다.
- 일본어 표시 이름은 견적 담당자에게 기존 표기를 확인한 뒤 넣습니다(9장). 그 전에는 영어 이름을 씁니다.
- 문구는 코드에서 분리합니다(D8, P7).

## 3. 할인·추가요금 색 (견적-3, 디자인 원칙 추가)

**이름은 검정(`--ink`), 계산 근거는 `--muted`. 색은 금액 숫자와 아이콘에만** 넣습니다.

| 변수(제안) | 용도 | 밝은 화면 | 다크 모드 | 흰 배경 대비 |
|---|---|---|---|---|
| `--discount` | 할인 금액·아이콘 | `#1A3E93` | `#86A4EA` | 9.8 |
| `--discount-bg` | 할인 연한 배경(필요할 때) | `#E9EFFB` | — | — |
| `--surcharge` | 추가요금 금액 | `#C2540A` | `#FA8C42` | 4.6 |
| `--surcharge-icon` | 추가요금 아이콘 | `#F06800` | `#FA8C42` | 3.1 (아이콘 기준 3 충족) |
| `--surcharge-bg` | 추가요금 연한 배경(필요할 때) | `#FEF0E7` | — | — |

- 금액 앞에는 항상 `−` / `+` 기호를 붙입니다(색만으로 구분하지 않음, D2·D7).
- 파랑은 New Campus 색(`#6E8FCB`)과, 주황은 주의 색(`#8A6A22`)·MCO 색(`#C9962E`)·Challenger 색(`#C23B4A`)과 겹치지 않게 고른 값입니다.
- 디자인 원칙 문서 2.2(기본 색)와 2.5(아이콘)에 이 표를 추가합니다(해야 할 일).

## 5. 캠퍼스 버튼 색 (견적-4)

Challenger · Premium · 혼합 버튼에 캠퍼스 색을 넣어 바로 구분되게 합니다(디자인 원칙 2.1 값).

| 버튼 | 선택됨 (배경 / 글자 / 테두리) | 선택 안 됨 |
|---|---|---|
| Challenger | `#F7E0E2` / `#7A1E2A` / `#C23B4A` | 흰 배경 + 이름 앞 캠퍼스 점 `#C23B4A` |
| Premium | `#E2ECE1` / `#214632` / `#5B8A6E` | 흰 배경 + 점 `#5B8A6E` |
| 혼합 | `#E4E6EA` / `#272A31` / `#4C5260` | 흰 배경 + 두 점(Challenger·Premium) |

- **버튼과 캠퍼스 칩에만** 캠퍼스 색을 씁니다. 견적 화면은 캠퍼스를 오가는 화면이라 `body[data-campus]`로 화면 전체 강조색·배경(Premium 아이보리)을 **바꾸지 않습니다.** 디자인 원칙의 "한 캠퍼스 화면이면 강조색이 바뀐다"의 예외로 기록합니다.
- 버튼 이름은 그대로 두어 색만으로 구분하지 않습니다(D2).
